## What a document costs (measured)

Means per document over a random sample of each benchmark (seed 0), read one document at a time by the final pipeline. Calls and tokens: for VAREX and DocuBench, the servers' own usage counters (nothing else using them); for the other four, measured side by side, each reply's own usage counted in the measuring process (`benchmarks/usage_meter.py`); both count the same requests. DocQuorum runs open weights on one H100 shared with other accounts' jobs: it pays no price per call, and the seconds are upper bounds (for the last four, also shared with each other's measurements). The dollar columns price the measured tokens (extraction model and parser) at the Qwen3.8-27B list price, $0.50 / $3.00 per million input / output tokens (`pricing.json`). Per-document rows: `results/costs/<benchmark>.json`.
