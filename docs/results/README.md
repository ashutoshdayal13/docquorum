# Results shown in the pipeline guide

The results tables are generated by `generate_tables.py` from the snapshots in this folder.
Each lists every published system and one DocQuorum row, placed by score; equal scores (at two decimals) share a rank.

| table | published systems | DocQuorum | rank |
|---|---|---:|---|
| ExtractBench (370 PDFs, value F1) | 47, from the ExtractBench leaderboard CSV (2 October 2026) | 95.43 | 3rd |
| UNIKIE-BENCH (4,472 images, macro F1) | 15, from the paper's Table 4 | 82.65 (with zoom re-reading) | 1st (Gemini-3-Pro 82.37) |
| VAREX (1,777 forms, exact match) | 20, from the image-modality leaderboard | 98.30 (with zoom re-reading) | 1st (Gemini 2.5 Pro 98.0) |
| LongArray-Extract (45 documents, accuracy) | 11, from Extend AI's results page | 98.05 | 2nd (Extend MAX 99.2) |
| UNIKIE-BENCH open (1,661 documents, macro F1) | 15, from the paper's open-category table | 72.33 (with zoom re-reading) | 2nd (Gemini-3-Pro 81.65) |
| DocuBench v0.2.0 (72 documents, accuracy) | 9, from the DocuBench leaderboard | 86.47 | 5th (DocuPipe 97.02) |

The ExtractBench row is the stored final outputs scored against the dataset as published now (revision `51bf3a0`);
on the earlier revision the pipeline was developed on, the same outputs score 95.25. The UNIKIE row is the quorum
over six readings, small images enlarged first (82.37 before). Source revisions and hashes are in [provenance](provenance.json).

- [Complete original ExtractBench CSV](extractbench-leaderboard.csv), including
  the additional precision/recall, grounding, latency and split-cost columns.
  Only line endings are normalized to LF; all rows and values are retained.
  Published source: [run-llama / ExtractBench, historical pinned revision](https://github.com/run-llama/ExtractBench/blob/c8e59696b19c50d904801390dedef8d292d529e7/leaderboard.csv).
- [Complete UNIKIE published table](unikie-published.json), from
  [UNIKIE-BENCH Table 4](https://arxiv.org/html/2602.07038v2#S4.T4).
  Every numerical cell was checked against the paper.
- [DocQuorum ExtractBench measurements](docquorum-extractbench.json), copied
  from the stored-primary and incremental-development provenance summaries.
- [DocQuorum UNIKIE measurements](docquorum-unikie.json), retaining scores,
  scenario values and configuration descriptions from the full coverage audit.
- [Snapshot hashes, source revisions and verification](provenance.json).

The [generator](generate_tables.py) checks snapshot hashes and emits
[the LaTeX tables](../results-tables.tex). `make -C docs` regenerates them when
the snapshots or generator change. Building uses local files only.

## Further schema-guided benchmarks

Published-system snapshots for the benchmarks run with the 27B pipeline
(`benchmarks/multibench/frozen27b.py`, `benchmarks/unikie/`). A complete table, every published
system plus one DocQuorum row, is rendered for a benchmark once its
`docquorum-<benchmark>.json` exists (written by `frozen27b.py <benchmark> package` after a complete
run); [TABLES.md](TABLES.md) holds every table in Markdown.

- [VAREX image-modality leaderboard](varex-published.json): 20 models, from the VAREX-Bench
  project page at revision `3cce9c1`.
- [LongArray-Extract](longarray-published.json): 11 systems, from Extend AI's results page.
- [UNIKIE-BENCH open category](unikie-open-published.json): 15 systems and all 8 scenarios,
  transcribed from the paper's open-category table; every average re-derived from its scenarios.
- [DocuBench v0.2.0](docubench-published.json): the 9 README leaderboard systems, recomputed from
  the repository's per-document `results/summary.csv`.
