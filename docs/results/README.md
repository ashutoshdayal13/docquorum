## Further schema-guided benchmarks

Published-system snapshots for the benchmarks run with the 27B pipeline
(`benchmarks/multibench/run.py`, `benchmarks/unikie/`). A complete table, every published
system plus one DocQuorum row, is rendered for a benchmark once its
`docquorum-<benchmark>.json` exists (written by `run.py <benchmark> package` after a complete
run); [TABLES.md](TABLES.md) holds every table in Markdown.

- [VAREX image-modality leaderboard](varex-published.json): 20 models, from the VAREX-Bench
  project page at revision `3cce9c1`.
- [LongArray-Extract](longarray-published.json): 11 systems, from Extend AI's results page.
- [UNIKIE-BENCH open category](unikie-open-published.json): 15 systems and all 8 scenarios,
  transcribed from the paper's open-category table; every average re-derived from its scenarios.
- [DocuBench v0.2.0](docubench-published.json): the 9 README leaderboard systems, recomputed from
  DocuBench's own per-document `results/summary.csv` (in its repository).

## DocQuorum's results and the code that reads them

- `docquorum-<benchmark>.json` (`varex`, `unikie`, `unikie-open`, `longarray`, `docubench`, `extractbench`): the reported
  score, its details, the stored result it comes from (`results/<benchmark>/<run>/`) and the earlier runs.
- [leaderboards.py](leaderboards.py): every benchmark's published systems and DocQuorum's result in one shape (place, the
  best published system below DocQuorum, best open and closed model), read by the generator and the flow deck.
- [system-types.json](system-types.json): the kind of each LongArray-Extract and DocuBench system (open model, closed
  model, commercial service, coding agent); the other benchmarks state it in their own tables.
- [pricing.json](pricing.json) and [pricing.py](pricing.py): list prices with their sources, and the cost of a measured
  document (`results/costs/`) at those prices. [docubench_costs.py](docubench_costs.py): each DocuBench system's cost
  and time per document from its 72 result files.
- [release.py](release.py): writes `RELEASE.json` (pipeline file hashes, every reported result and its files, the changes).
- `generate_tables.py` also writes the results and cost blocks of the top-level README and the table above.
